# 더코 — 한국 영화 명대사·명장면 퀴즈

한국 영화의 명대사 한 줄, 그리고 명장면 한 컷으로 즐기는 4지선다 퀴즈.
빌드 도구 없이 정적 파일만으로 동작하고, 아이폰 사파리(390×844) 기준으로 만들었습니다.

- 실서버: **https://movie-quiz.vercel.app**
- 저장소: https://github.com/leesh33/movie-quiz
- 백엔드 없음 · 최고 점수는 브라우저 `localStorage`(`theko.stats.v1`)에 저장

## 플레이 방식

1. **모드**를 고릅니다.
   - `💬 명대사 → 영화 맞추기` : 대사를 읽고 영화 제목 4지선다
   - `🖼️ 명장면 → 대사 맞추기` : 장면 일러스트를 보고 실제 대사 4지선다
   - `🎲 혼합 퀴즈` : 두 유형을 섞어 10문제
2. **장르**를 고릅니다. `전체(랜덤)` · `범죄·느와르` · `코미디·휴먼` · `로맨스·멜로` · `액션·스릴러` · `드라마·사극`
3. 상단 진행바(`3 / 10`)와 연속 콤보가 표시되고, 막히면 **힌트 보기(1회)** 로 개봉연도·감독·주연을 볼 수 있습니다.
4. 선택하면 즉시 정답/오답 표시와 함께 **짧은 해설**(영화·연도·감독·주연·장면 배경)이 나옵니다.
5. 라운드가 끝나면 점수·등급 칭호·틀린 문제 다시 보기·다른 장르 도전이 이어집니다.

## 문제 은행

- **총 65문제** = 5개 장르 × (명대사 10 + 명장면 3)
- 등장 작품 42편 — 올드보이, 신세계, 범죄도시, 타짜, 기생충, 극한직업, 건축학개론, 뷰티 인사이드, 부산행, 명량, 왕의 남자, 광해, 서울의 봄, 8월의 크리스마스, 봄날은 간다, 살인의 추억, 베테랑, 내부자들, 부당거래, 추격자, 친구, 7번방의 선물, 써니, 헤어질 결심, 아가씨, 곡성, 불한당, 쉬리, 박하사탕, 비트, 초록물고기, 시, 택시운전사, 변호인, 장화 홍련 등
- 모든 대사는 실제 영화 대사이며, 오답 보기 3개도 같은 장르·시대의 실제 작품 대사로 구성해 찍기 어렵게 했습니다.
- 개봉연도·감독·주연은 힌트와 해설에 사용합니다.

## 구조

```
movie-quiz-web/
  index.html          화면 3개(홈·퀴즈·결과)
  styles.css          시네마틱 다크 + 골드 테마, 390×844 기준
  app.js              라운드 생성·채점·콤보·힌트·기록 저장
  data/questions.js   문제 은행 65문제 (window.THEKO_DATA)
  assets/scenes/      명장면 일러스트 15장
```

## 로컬에서 열기

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.
(로컬 서버로 띄우려면 `python3 -m http.server 8000` 후 http://localhost:8000)
